# ADR-003: Разделение состояния — Query для сервера, Context для UI

**Статус:** принято

**Контекст.** В приложении два вида состояния: серверные данные (дерево, патчи) и UI
(режим «Дерево/Таблица», выделенный узел, текст фильтра, сортировка, expanded-набор).

**Решение.** Серверное состояние — только TanStack Query. UI-состояние — один React
Context (`ui-state.tsx`) с редьюсером; производные значения (debounce фильтра, отсортированные
строки) — `useMemo` в хуках, а не в состоянии.

**Альтернативы.**
- *Redux/Zustand* — избыточно: нет cross-cutting экшенов, состояние локально одному экрану.
- *URL как состояние* — приятный bonus (deep-link на узел), но не требование задания;
  отложено, чтобы не раздувать скоуп этапов 01–03.

**Последствия.** Никаких библиотек состояния; выделение в дереве и таблице живёт в одном
месте, что даёт требуемую связь «клик по строке → выделение в дереве».
