# ADR-004: Агрегация — однопроходный DFS c Map-кэшем и веточным пересчётом

**Статус:** принято

**Контекст.** Требуется: агрегаты «узел + все потомки», взвешенная по headcount
эффективность, расчёт один раз после загрузки, а при live-патче — пересчёт только
затронутого узла и предков.

**Решение.** После загрузки — один post-order DFS, результат `Map<id, Aggregates>`.
При патче узла X — обновить X и пройти вверх по `parentOf` до корней, пересчитывая
агрегаты ветки из кэшированных агрегатов детей (дети X не пересчитываются: их поддеревья
не менялись).

**Альтернативы.**
- *Полный пересчёт на каждый патч* — O(n) на патч при частоте ~0.3с/патч; напрасная работа,
  задание прямо требует иначе. Отклонено.
- *Библиотеки деревьев* — не нужны для трёх уровней и 40+ узлов.

**Последствия.** Чистая функция в `domain/aggregation.ts` покрывается unit-тестом
(требование задания): фиксируются инварианты листа, внутреннего узла, взвешенного среднего
и инкрементального пересчёта (результат === полному пересчёту).
